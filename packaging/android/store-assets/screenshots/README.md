# Store screenshots

Place **landscape** screenshots here before submitting to app stores.

## Requirements

| Store | Minimum | Notes |
|-------|---------|-------|
| Google Play | 2 | Phone/tablet; game runs in landscape |
| Huawei AppGallery | 2+ | Same assets as Play |
| Xiaomi GetApps | 3+ | Landscape, original orientation |
| RuStore | 2+ | Per console requirements |

## How to capture

1. Run the app on an emulator or device (debug or release APK).
2. Capture in-game scenes: main menu, world view, settings.
3. Save as PNG or JPEG into this folder, e.g.:
   - `01-menu.png`
   - `02-world.png`
   - `03-settings.png`

Optional for Google Play: feature graphic **1024×500** → `feature-graphic.png` in this folder.
