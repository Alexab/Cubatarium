Reference file names classify material families. A small set of scalar properties, including foliage alpha coverage, calibrates newly drawn masks. Source pixel patterns are not copied into generated textures.
Minecraft Java Edition 26.3 counts are used only as a catalog-size benchmark; no Minecraft assets are included.
