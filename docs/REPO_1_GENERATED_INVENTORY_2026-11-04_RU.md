# REPO-1: инвентаризация generated/runtime файлов

Дата: 2026-11-04.

## Наблюдения

- `resource_packs/cubatarium_worldgen_cc0`: 4352 tracked файла. Это production source pack, а не автоматически мусор; исключение из git требует отдельного решения о хранении и воспроизводимой генерации.
- `objects`: 51 tracked JSON.
- `tools/archive/tmp`: 58 tracked временных research scripts. Перед удалением каждого кандидата нужно проверить ссылки из документации/CI и сохранить воспроизводимость соответствующих экспериментов.
- В `bin/` остаются многочисленные untracked captures, сравнения, audit-выходы и локальные scripts. Существующий `.gitignore` покрывает runtime trees, suite reports и часть scratch, но не весь исторический visual-output набор.
- Текущий `build/desktop-msvc` сохранён и используется для Release-проверок.

Полная оценка размера через `du -sh bin cache build/desktop-msvc resource_packs/cubatarium_worldgen_cc0` превысила 120 с и была остановлена. Точный размер в этом отчёте не утверждается.

## Изменения

Добавлены только точечные ignore-правила для наблюдаемых локальных `/.zcode/`, `/cache/` и `/stall_log.txt`. Ни один файл или каталог не удалён, tracked generated pack не изменён, миры и build trees не затронуты.

## Открытые действия

1. Составить согласованный список tracked generated files, которые действительно можно воспроизводимо создавать, прежде чем менять их хранение.
2. Для одноразовых scripts подготовить per-file список и проверить ссылки.
3. Для очистки `bin/`, миров и build trees получить отдельное явное разрешение с сохранением baseline/reference артефактов.

Этап завершён только как безопасная инвентаризация; очистка не выполнялась.
