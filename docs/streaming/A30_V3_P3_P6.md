## Пост-коммитная оговорка (A31, HEAD `243e817d`)

Вышеуказанные изменения реализуют scaffolding, но не закрывают соответствующие
production-контракты. Emerge подставляет поколение `1`, когда published peer
отсутствует, а затем сравнивает provisional generation с тем же значением;
эти проверки не подтверждают нужную peer/seam coverage generation. Callback
сам по себе означает first drawable, но не требуемую версию грани. Fluid defer
добавляет задание без flags и тут же снимает одно задание из очереди; полученный
summary не устанавливается. После возврата `false` внешний slice-builder сразу
выполняет синхронный CPU scan всех 16×16 столбцов. Поэтому прежнюю формулировку
«hitch enqueue» нельзя трактовать как устранение main-thread hitch. Static pack
cache к тому же штампуется только content revision Y=0 при чтении других Y.
См. [`A31_REAUDIT_2026-09-23.md`](A31_REAUDIT_2026-09-23.md).
