# Creature texture credits

Textures imported or derived from Luanti community mods (MIT / CC BY-SA as noted per mod).

| Mod | Author | License | Used for |
|-----|--------|---------|----------|
| mobs_animal | TenPlus1 | MIT | sheep, cow, chicken, bunny, rat, bee, … |
| mobs_monster | TenPlus1 | MIT | oerkki, sand_monster, stone_monster, … |
| dmobs | TenPlus1 | MIT | skeleton, badger, hedgehog, fox, … |
| animalworld | Skandarella | MIT | wolf, pig, trout, shark, aquatic proxies |

Placeholder species (dolphin, whale, kitten, warthog, …) use **proxy textures** from the closest Luanti source until upstream PNGs are available. See `tools/fix_placeholder_creature_textures.py`.

Do **not** ship vanilla Mojang Java/Bedrock entity PNGs in this repository.
