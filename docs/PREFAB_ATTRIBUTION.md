# Prefab attribution

Cubatarium prefab objects are multi-block templates stored in [`prefabs/`](../prefabs/). Many are ported from open Minetest/Luanti schematics with canonical block name mapping.

## Tooling

- Fetch: [`tools/fetch_third_party_schematics.py`](../tools/fetch_third_party_schematics.py)
- Convert MTS → prefab JSON: [`tools/mts_to_prefab.py`](../tools/mts_to_prefab.py)
- Block mapping: [`tools/minetest_node_map.yaml`](../tools/minetest_node_map.yaml)
- Registry: [`tools/prefab_manifest.yaml`](../tools/prefab_manifest.yaml)
- Worldgen rules: [`content/prefab_features.json`](../content/prefab_features.json) (generated from manifest)
