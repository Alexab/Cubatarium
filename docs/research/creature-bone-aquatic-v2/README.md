# R4 — последние три bone-вида

Baseline: `b35f00a75`. Сравнения `trout.png`, `squid.png`, `dolphin.png`
используют одну мировую шкалу: исходная модель, неудачная прежняя переработка,
нынешний кандидат. Генератор не читает baseline; сравнение — research tooling.

`native_approved_<id>.png` — листы реальных кадров Release-приложения:
четыре ракурса, восемь фаз основного движения, восемь Run и восемь Action.
Сырые кадры и настоящая 64px иконка (индекс 12) находятся в `native_candidate`.
Имя листа не является решением о приёмке: решение и точные hashes — `review.json`.
Reviewer — Codex, не пользователь.

Подводные проверки выполнены отдельно для каждого вида через
`tools/flight_sim_run.py`, мир `World_254`, `bin/Cubatarium.exe` Release:
`runtime_trout`, `runtime_squid`, `runtime_dolphin`. Контексты и отчёты
сохраняют точные hashes ресурсов и executable. В каждом `frame_001.png`
видна нужная модель в настоящей воде.

В автоматической проверке mesh/hierarchy используются 64 фазы Swim:
латеральный хвост форели, вертикальные лопасти дельфина, восемь движущихся
дистальных сегментов кальмара и непрерывность их соединений. Это отдельное
доказательство работоспособности, не замена прямому визуальному просмотру.

Performance gates отключены: эти запуски не дают performance PASS.
Полная R6-матрица и повторная сборка всех 61 ресурсов текущим генератором
ещё предстоят.
