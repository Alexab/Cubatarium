# Удержание моба при прицеливании — 2026-11-14

После ручной игровой проверки обнаружено выпадение моба при подъёме взгляда
после захвата у земли. Это отдельный дефект от таймера сопротивления.

Причина: первое препятствие на пути удерживаемого тела отпускало хват при
отставании от желаемой точки более чем на 0.5 блока. При взгляде вниз точка
оказывалась в земле. Дополнительно проверка разрыва связи сравнивала положение
груза с новой точкой прицеливания, что могло отпускать крупный груз при резком
развороте камеры.

Исправление: до трёх последовательных swept-проверок перемещают груз и
проецируют оставшееся движение вдоль препятствий. При упоре груз остаётся в
последней доступной позиции; подъём взгляда позволяет поднять его от пола.
Неготовые коллизии приостанавливают перемещение. Разрыв связи по расстоянию
теперь проверяет реальную удалённость груза от глаз носителя (4 блока).
Сопротивление существа и усталость носителя продолжают ограничивать удержание.

Проверка выполнена в основной директории `E:/Work/Home/Cubatarium`, на `develop`.
Использован отдельный мир `CarryAimQA`, только Release:

```
cmake --build build/desktop-msvc --config Release --target Cubatarium --parallel 8
```

Загрузка выполнена через `tools/flight_sim_run.py` с `bin/Cubatarium.exe`.
В native fixture добавлены четыре регрессии: взгляд вниз у пола, подъём от
−70° до +75°, разворот на 180°, ограничение груза потолком без проникновения.
Все четыре **падают на прежнем коде** (`before.json`, 50 проверок без отдельного
Survival-loop). После исправления проходят **51/51 native**, включая прежние
проверки бросков, сопротивления, урона, сохранений и Survival-loop; **24/24**
раскладки UI. В `after.json` и `window.json` нет отказов.

Инкрементальная Release-сборка завершилась с кодом 0; static EXE verification
прошла. Style — 0 нарушений, clang-format — 3 файла, include gate — без новых
нарушений (38 разрешённых legacy-рёбер и 42 информационных обратных зависимости).
Глобальные performance-gates этим прогоном не оценивались.
