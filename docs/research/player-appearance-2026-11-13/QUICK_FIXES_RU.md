# Быстрый разбор остатков существ — 13 ноября 2026

Лимит быстрых исправлений: не более двух часов. Расширение этой части остановлено после проверки исходных трёх падений. Остальная работа относится к редактору игрока и обязательной приёмке его экипировки.

- Lobster: устранена пустая выборка клешни. Кончик определяется по фактической геометрии соответствующей кости; проверка требует непустую выборку. Полный invertebrate test проходит.
- Orc: Walk содержит четыре шага, Run — три в общем цикле. Проверка скорости определяет длительность шага по повторению канала стопы. Отдельный test_orc_macro_loop_measures_each_complete_stride проходит для всех семи шагов. Далее выявлено старое нарушение контакта: minY 0.001455 блока при допуске 0.001. Допуск сохранён; требуется отдельная доводка движения.
- Treeman: жёсткая часть стопы остаётся минимум на 0.0625 блока выше плоскости. Нулевая минимальная высота всего меша не означает опору стопы. Строгая проверка сохранена. creature_stance_diagnostics.json содержит исходный model-space; creature_stance_world_diagnostics.json — полную трансформацию в плоский мир с движением тела вдоль +Z. Скорость центра стопы сама по себе не доказывает footplant при перекате; высота стопы от добавления движения не меняется.
- owl.orig.bin в текущем develop уже отсутствует среди tracked assets и в исходном каталоге owl. Активный glTF использует model.bin; удаление не требуется.
- QA экипировки: старые arms/hands исключены из списка обязательных файлов — текущий каталог содержит head/chest/legs/feet.
- При приёмке полной брони найдены оторванные сапоги: legacy offset [0,-0.35,0.05] применялся поверх bone_volume fitting. Offset обнулён для copper/gold/iron/leather и в itemgen. Regions ног/стоп соответствуют действующим слотам 2/3 и делят ногу без зазора. Тест генератора и C++ fitting проходят; native-лист полной экипировки не обрезан, сапоги находятся на стопах.

Fidelity suite: 35/37, два оставшихся падения — контакт Treeman и Orc. Остальные MOT-01..04, PHY-01, PERF-01 и Android остаются отдельными задачами.
