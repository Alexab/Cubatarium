# Быстрый разбор остатков существ — 13 ноября 2026

Лимит быстрых исправлений: не более двух часов. Расширение этой части остановлено после проверки исходных трёх падений; оставшаяся работа относится к редактору игрока.

- Lobster: устранена пустая выборка клешни. Кончик определяется по фактической геометрии соответствующей кости; проверка требует непустую выборку. Полный invertebrate test проходит.
- Orc: Walk содержит четыре шага, Run — три в общем цикле. Проверка скорости теперь определяет длительность шага по повторению канала стопы. При дальнейшем прохождении выявлено отдельное старое нарушение контакта: минимальная высота меша 0.001455 блока при допуске 0.001. Допуск не ослаблялся; требуется отдельная доводка движения.
- Arboreal: подтверждён реальный дефект Treeman — жёсткая часть стопы остаётся минимум на 0.0625 блока выше плоскости. Нулевая минимальная высота всего меша не означает опору стопы. Проверка сохранена; world-space диагностика в creature_stance_diagnostics.json показывает высоты и скорости в опорных интервалах. Добавление скорости движения тела меняет горизонтальную скорость, но не исправляет высоту стопы.
- owl.orig.bin в текущем develop уже отсутствует среди tracked assets и в исходном каталоге owl. Активный glTF использует model.bin; дополнительное удаление не требуется.
- QA экипировки: старые arms/hands исключены из списка обязательных файлов — текущий каталог содержит head/chest/legs/feet.

Остаются отдельными задачами: MOT-01..04, PHY-01, PERF-01, Android; контакт Treeman и Orc. Старые отчёты и строгие проверки не объявляются полностью зелёными.
