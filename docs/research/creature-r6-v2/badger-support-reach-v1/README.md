# Достижимость опоры: rig и ограничения badger

Исследование 2026-11-12, цель active. Скрипт
`tools/research/analyze_creature_badger_support_reach.py` читает фактические
glTF pivots/transforms `badger_stride_v3`. Это аналитическая геометрия цепи
на 1025 фазах, **не IK solver, не terrain/world capture и не приёмка походки**.
Источник и hash анализатора записаны в [reach.json](reach.json).

## Исходная жёсткая лапа

Тест намеренно задаёт более строгую опору, чем естественный перекат лапы:
горизонтальная стопа, фиксированный yaw, диагональные пары, duty 50%,
заранее заданная body-relative траектория центра подошвы. Это диагностический
contract, не утверждённый gait badger. Скорость .475 block/s, clip rate .176,
14 шагов на macroloop — из предыдущего измеренного world fixture.

У исходного rig лапа и нижний сегмент — одна жёсткая деталь. При заданной
ориентации лапы позиция нижнего сустава уже определена, поэтому длина верхней
кости 3/16 задаёт единственную высоту root для каждой опорной ноги. Одна общая
root Y не может удовлетворить две разные требуемые высоты.

![Required root per support paw](required_root.png)

При исходном slow roll ±20° и spine yaw требуемые root расходятся до
**0.11829 block**, median0.07954. В 98.54% samples spread>0.002 block.
Контроль с выключенными body/spine rotations даёт совпадение до4.2e−17 block:
формула и симметричная опорная постановка согласуются.

Вывод ограничен этим flat-paw contract. Это **не** доказательство, что rig
непригоден для heel/toe roll, другого gait или стилизованной походки. Нельзя
выдавать пересчёт root Y за решение XZ foot locking или растягивать кости.

## Необходимая проверка дополнительной артикуляции

Для scratch независимого support joint на Y0.5 (исходный lower pivot Y2)
длины цепи 3/16 и1.5/16. При пробном knee range0…120° вычислены допустимые
интервалы root Y каждой опорной ноги и их пересечение. Это **необходимое**
условие, ещё без hip/foot limits, bend pole, skin quality и geometry collisions.

| Body/hip roll amplitude | Infeasible /1025 | Minimum shared-root interval, block |
|---|---:|---:|
|0°|0|0.08891|
|8°|0|0.04326|
|12°|0|0.02104|
|20°|333|−0.02107|

Добавить foot joints недостаточно, чтобы автоматически пройти выбранную опору
при прежнем whole-rig roll. Следующий scratch опыт разделяет наклон таза и
верхнего корпуса: сохранить выразительный верхний slow roll20°, дать hip
controls roll8°, затем решать опору с ограничениями. Эти числа — параметры
пилота, не общие настройки для всех семейств и не новый допуск приёмки.
