# Penguin belly v1: отклонённый кандидат

Собственный изолированный рецепт увеличивает depth trunk с5 до6 texels и
сдвигает origin Z с−1 в−4. Rig/weights/17 animation arrays/definition сохранены,
Khronos validation без ошибок. Native three-way sheets непосредственно
просмотрены: чрезмерный вынос брюшка создаёт плоскую выступающую панель,
особенно в горизонтальной позе. **Не публиковать**; решение и SHA —
`visual_review.json`. Production ресурсы не менялись.

Более умеренный [v2](../penguin_belly_v2/README.md) сохраняет заднюю грань и
после дополнительного fluid/world/full-turn review опубликован как R5 revision;
полная R6 и wet/dry terrain/contact приёмка ещё открыты. Исторические
original/own-before captures v1 переиспользованы v2 с проверкой всех inputs,
одинакового EXE/profile/shaders и сохранением исходных timestamps.
