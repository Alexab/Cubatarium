# Исправление forward axis и R5 penguin / owl

Финальная приёмка семи видов — `review.json`: пять ранее переработанных
млекопитающих и две новые птицы. Reviewer — Codex, не пользователь.
Предыдущие reviews малой/средней R5-групп исторические; для текущих bundles
этих пяти действует данный review. `creature-gltf-birds-v2` — промежуточная
диагностика до исправления направления и окончательной формы пальцев/крыльев.

`forward_axis_correction.json` доказывает, что позиции, UV, веса, nodes/skin
и PNG пяти млекопитающих сохранены. Исправлены модельный yaw и порядок фаз
Walk/Run. Теперь направление головы и откат стопы в опоре проверяются вместе
с контактом. В рецептах явно указан перед +Z или −Z; runtime существа всегда
смотрит по +Z до применения yaw существа. Первые четыре glTF-пилота были +Z.

В `index.html` — равномасштабные baseline/старый generic/новый вариант,
полные native-листы и отдельные фазы Swim/Glide. Средний ряд сравнения показывает
старую неудачную generic-переработку, а не предыдущую хорошую модель до axis fix.
`native_candidate` содержит 29 настоящих кадров Release-приложения на вид.
Дополнительные восемь фаз — `native_swim` и `native_glide`. Кончики крыльев
в новом preview не обрезаны: camera envelope вычислен по реальному skinning
полного цикла и не меняется по фазам. Collider и мировой размер сохранены.

Мировые кадры: `runtime_close_<id>`, обычно frame_001; для warthog — frame_002,
поскольку frame_001 пришёл до завершения стартовой QA-разметки и был пустым.
`world_final.png` собирает только финальные кадры с видимой нужной моделью.
Подводный `runtime_penguin_water/frame_001.png` показывает Tread/idle загрузку;
native Swim проверяет отдельную горизонтальную позу. Непрерывный маршрут
плавания этим не заявлен. Имя fly у пингвина — исходное имя swim-клипа,
способность летать не включалась.

После обновления fingerprint иконок до v3 выполнен обычный Release-запуск
из bin/models, без подмены asset root. Контекст — `context_production_release.json`;
`production_preview_parity.json` подтверждает пиксельное совпадение всех 58
кадров двух птиц с QA. `runtime_production/frame_002.png` просмотрен: оба вида
видны, сова использует взмах. Это проверка двух опубликованных видов,
не завершение глобальной R6-матрицы.

`metrics.json` и sampled die бородавочника воспроизводятся через
`tools/research/measure_creature_gltf_motion.py` с QA-каталогом
`assetgen_output/creatures/gltf_forward_birds_v2/models`.
Время/матрицы/веса берутся из экспортированного glTF. Die остаётся asset
capability, без отдельного runtime Death state. Performance gates отключены;
performance PASS не заявлен. Полная R6-матрица, forward/stance аудит остальных
backend и воспроизводимость всех 61 ресурсов текущим генератором ещё впереди.
