# Dungeon master / land guard — fidelity v2

Прямо приняты Codex после просмотра точных final native, comparison, world
и UI artifacts; это не подпись пользователя. Bundles и обязательные PNG
закреплены в `review.json`. Эта волна закрывает R5 двух видов, не всю R6.

## Близость к исходникам и собственный облик

Оригиналы b35f00a75 используют одинаковую сетку: очень длинный массивный
торс, короткие ноги, длинные руки, низкая голова с выступом вперёд.
Все эти крупные массы сохранены. Исходники дополнительно просмотрены в
нынешнем Release: `../creature-monster-baseline-v2/native_baseline`,
контекст `context_guardians_baseline.json`.

Dungeon master сохраняет коричневый характер: собственные тёмные
ржаво-каменные слои, редкие светлые поля, тяжёлая надбровная часть,
бледные глаза/зубы и концы когтей. Первый вариант был слишком светлым
и имел отдельные мелкие тёмные точки; после native review он затемнён,
слои сделаны более связными. Чужие пиксели и сетка не копировались.

Land guard сохраняет зелёный каменный материал и широкую сторожевую
форму. Собственные мшистые верхние поля, каменные слои, светлая лицевая
маска, цельная надбровная арка, боковые щёчные полосы и наручи.
Его действие начинается подъёмом предплечий в защитную позу, затем ударом.
Dungeon master сначала заметно отводит кисти назад, затем выбрасывает вперёд.
Таким образом, одинаковая исходная база получила различимые собственные
детали и разные осмысленные attack clips.

| Вид | Baseline X/Y/Z, блоки | Собственный X/Y/Z |
|---|---|---|
| dungeon_master | 1.654700 / 2.668601 / 0.951253 | 1.6875 / 2.6875 / 1.0125 |
| land_guard | 1.654700 / 2.668601 / 0.951253 | 1.6875 / 2.6875 / 1.0125 |

Ширина +2.0%, высота +0.7%, глубина +6.4% с небольшим выступом брови.
Это явно просмотренное изменение, не auto-fit по collider. Gameplay bounds,
скорости, habitat, атрибуты и behavior settings сохранены. Head занимает
низкую часть верхнего корпуса и выступает вперёд; плоский тонкий гуманоид
прежнего генератора не оставлен как приемлемая анатомия.

## Скелет, движение и проверки

У каждого 17 реально weighted joints против двух у исходного glTF
(исходная palette семь). Отдельные spine/neck/head/jaw, плечо/локоть/кисть,
бедро/колено/стопа. Сохранены idle/walk/run/punch. Die в оригиналах не было.
Walk/Run/Punch имеют по 129 ключей, контакт проверен в 257 фазах с
промежутками между ключами: −0.000110…+0.000448 блока.

Проверки actual exported skinning покрывают закрытые кольца локтей/коленей,
проксимальное крепление на корпусе, swing clearance, правильный откат при
опоре, возврат циклов и исходную позу после удара. Частота Walk/Run согласована
со штатной walk_speed через реальную длину опорного хода стопы.
Проверяется реальное отведение кистей dungeon master назад перед ударом,
высота защитной фазы land guard, затем движение кистей вперёд. Геометрические
landmarks подтверждают низкую голову, доминирующий широкий торс и взгляд
в entity +Z после runtime yaw. Наручи остаются жёсткими: взаимные расстояния
всех их 24 вершин сохраняются при действии, вместо rubber deformation.

## Доказательства

- `<id>.png`: baseline / предыдущая версия / кандидат, шесть ракурсов
  в одной мировой шкале для каждого вида.
- `native_approved_<id>.png`: настоящие четыре стороны и по восемь фаз
  locomotion/Run/Action. Имя файла не подменяет решение review.
- `icons_final.png`: настоящие 64px иконки, увеличенные nearest neighbour.
- `runtime_final_<id>/frame_002.png`, `context_final_<id>.json`: финальные
  world-кадры с реальными QA-актёрами, точные payload/exe/shader hashes.
- `metrics.json`, `rig_capability_audit.json`: габариты, контакт, periods
  и действительные возможности ригов.
- `pilot_dungeon_master`: диагностическая первая версия до коррекции
  палитры/слоёв и уточнения замаха; не финальное acceptance evidence.

32 fidelity и 9 quality Python tests проходят. Использовался только Release,
world проверялся через `tools/flight_sim_run.py`. Performance gates этих
восьмисекундных art probes отключены, performance PASS не заявляется.
Обычный каталог проверен отдельно через `--production` для каждого вида:
оба действительно появились в мире, свежие relocation dumps и контексты
с `qa_models_override:false` сохранены. Все 58/58 native-кадров пиксельно
совпали с принятыми кандидатами; production-world кадры прямо просмотрены.
Payload в `models/` и `bin/models/` сверены с точными review bundles.
Результат — `production_preview_parity.json`.
Полные маршруты, переходы/края travelScale, equipment/FP/save-load, платформы,
производительность и воспроизводимость всех 61 ресурсов остаются R6.
