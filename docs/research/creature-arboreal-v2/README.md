# R5: tree_monster / treeman / golem

Приняты и опубликованы после прямого просмотра baseline/comparison,
полных native sheets, world и настоящих 64px UI-иконок. Reviewer Codex,
не подпись пользователя. Полная R6 ещё не пройдена.

## Внешний вид и масштаб

Tree monster снова имеет древесный ствол, расколотую древесную маску с
золотистыми глазами, корни и пространственную ветвистую крону. Шесть цепей
ветвей получают собственные слабые фазы ветра. Волокна собственного материала
следуют направлению наклонных веток. Это не прежний тонкий коробчатый человек.

Treeman сохраняет высокую изогнутую зелёную древесную фигуру, большую
ступенчатую лиственную крону, длинные руки с четырьмя пальцами на каждой
кисти и разнесённые корневые ноги. После comparison review увеличены массы
ствола, рук, голеней и корней. Собственная группировка листовых цветовых полей
и фактура коры созданы генератором, исходные пиксели/геометрия не копировались.

Голем снова сутулый, широкоплечий, с низкой выступающей головой и длинными
руками почти до земли. Каменные элементы жёсткие, тёмные перекрывающие
сердцевины закрывают шарниры, светлые минеральные слои связывают материал.
Первоначальные слишком чёрные сердцевины осветлены после native review.

| Вид | Baseline X/Y/Z, блоки | Свой X/Y/Z, блоки |
|---|---|---|
| tree_monster | 1.124633 / 2.389074 / 1.004659 | 1.110599 / 2.362500 / 1.001330 |
| treeman | 1.803213 / 4.872025 / 1.825625 | 1.812500 / 4.875000 / 1.812500 |
| golem | 1.486930 / 2.446046 / 1.081969 | 1.625000 / 2.437500 / 1.031250 |

У голема ширина больше на 9.3% из-за объёмных плечевых камней, глубина
меньше на 4.7%; изменение прямо просмотрено и принято. Gameplay bounds,
locomotion, habitat, catalog, attributes и behavior сохранены относительно
baseline. В частности, огромный исходный collider treeman не уменьшен
под его более узкую видимую сетку.

## Риги и движение

Реально weighted joints: 27 / 23 / 16 против одного у каждого исходника.
Сохранены все исходные idle/walk/run/punch; исходного die у этих видов нет.
Наклонные древесные сегменты используют общие сечения суставов; переход
веса завершён до целого торцевого кольца. Закрытие коленей/локтей/ветвей
проверяется на реально экспортированной skinned геометрии в движении.
Все восемь пальцев treeman сгибаются относительно кисти. У голема взаимные
расстояния всех 24 вершин каждой каменной детали сохраняются; единственное
явное мягкое соединение — waist_connector.

Walk/Run имеют 257 ключей. Полный skinning проверен в 513 фазах,
включая межключевые: −0.000043…+0.000808 блока. Найденная ранее деталь
щиколотки голема уходила в пол в Run на 0.010894 блока; её размер и
положение исправлены до принятой версии. Проверяются возврат циклов,
откат/подъём стопы, согласование длины опоры с walk_speed и подъём рук
голема при ударе. Тест учитывает полупериодный сдвиг правой ноги.

## Доказательства и ограничения

`<id>.png` — равный масштаб baseline/плохой генерации/новой версии;
`native_approved_<id>.png` — настоящие четыре ракурса и по восемь фаз
Walk/Run/Action. Название файла не заменяет review. `icons_final.png` —
настоящие 64px иконки с nearest-neighbour увеличением.
`runtime_final_<id>/frame_002.png` и `context_final_<id>.json` — финальные
Release actors, точные hashes моделей/exe/shaders. `metrics.json` и
`rig_capability_audit.json` — геометрия, контакт и функциональные проверки.
`pilot_*` — диагностические ранние версии, не acceptance evidence.

QA-выбор сухого места теперь проверяет полный объём тела штатным
CanSpawnCreatureAt и сохраняет найденную корректную позицию при relocation.
Неудачный baseline запуск без фактического treeman отклонён; успешный
повтор трёх исходников находится в creature-monster-baseline-v2.
Использовался только Release через tools/flight_sim_run.py.
33 fidelity (32 прежних плюс новая проверка этой тройки), 9 quality и
9 C++ tests проходят. Performance gates art probes выключены; performance
PASS не заявляется. Маршруты, yaw clearance, переходы/края travelScale,
equipment/FP/save-load, платформы и воспроизводимость всех 61 ресурсов
актуальным генератором остаются R6.

Обычный каталог отдельно проверен через --production для каждого вида.
Все три действительно появились, capture contexts свежие и без QA-подмены
моделей. 87/87 native кадров пиксельно совпали с принятыми кандидатами.
Production-world кадры прямо просмотрены, payload обоих опубликованных
каталогов соответствует review. См. production_preview_parity.json.
