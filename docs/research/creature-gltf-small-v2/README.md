# R5 — rat / kitten / hedgehog

`index.html` содержит сравнения и листы движения. В каждом сравнении одна
мировая шкала: baseline `b35f00a75`, неудачная прежняя переработка, новый вариант.
Генератор не читает исходные геометрию или текстуры; baseline использует только
research tooling. Данные анатомии, материалы и движения находятся в наших YAML.

В `native_candidate` сохранены 29 настоящих кадров Release-приложения на вид:
четыре ракурса, восемь фаз основного движения, 64px иконка (12), восемь Run и
восемь Action. Крыса сохраняет исходный punch; Action котёнка и ежа остаётся
отображённым на walk, как в исходных definitions.

`runtime_wave/frame_001.png` показывает мировой масштаб всей тройки.
Для оценки деталей отдельно выполнены `runtime_close_rat`,
`runtime_close_kitten`, `runtime_close_hedgehog`: финальный `frame_001.png`
каждого содержит нужное существо целиком. Камера сопровождает фактическое
положение после физических тиков, размер модели не меняется. Предыдущие
обрезанные close-кадры перезаписаны и в приёмке не используются.
Hashes входных ресурсов и executable сохраняют `context_*.json`.

`metrics.json` содержит размеры baseline/candidate и измерения контакта лап
через экспортированные glTF веса и joint matrices. Тест отдельно проверяет
64 фазы Walk/Run, швы циклов, смешанные веса, движение каждой лапы и форму
заострённых ушей/приподнимающегося хвоста котёнка. Тесты не заменяют прямого
визуального просмотра.

`review.json` — решение Codex, не подпись пользователя. Имя файла
`native_approved_<id>.png` само по себе не означает приёмку. Performance gates
во flight-запусках отключены; performance PASS не заявлен. Полная R6-матрица
и воспроизводимость всех 61 ресурсов текущим генератором ещё впереди.
